Cyan Civilization **1.0.4** adds **Emotecraft** for shared multiplayer emotes.

- Native Fabric **2.4.12+1.21.1** build with Player Animation Library and Bendy bundled.
- Enabled by default, with a toggle under optional client-side mods.
- Fresh installs use **F10** for the Emotecraft wheel to avoid the existing backpack B binding. Existing players can assign the wheel in Controls > Key Binds > Emotecraft; updates preserve their existing settings.
- The attached **Emotecraft-Server-Update.zip** contains the matching server mod. Stop the Fedora server, add its JAR to the server's mods folder, then restart. Every participating player needs Emotecraft enabled.
- Use Emotecraft's wheel for shared emotes. Punchy Moves' separate emote wheel remains local-only.

Client tests passed loading nine built-in emotes, starting/stopping playback, and the existing slab-rendering checks. A dedicated server also started and shut down cleanly with Emotecraft. Two-player delivery on Fedora still needs checking after applying the server update.

Reopen Comp Craft and use **Update & Play**. Existing worlds, keybinds and configs are preserved. The launcher remains at **1.1.1**; the pack is now **1.0.4**.
