Cyan Civilization **1.0.5** adds **wWaypoints 0.8.1** for Minecraft 1.21.1 / Fabric.

- Enabled by default, with a toggle under optional client-side mods.
- Adds in-world waypoint markers, groups, folders and an editor. Xaero's Minimap and World Map remain installed; their existing waypoint data is preserved.
- New installations use **F12** for the wWaypoints menu. Its quick-create, settings and clear-unlocked shortcuts start unbound to avoid conflicts with existing controls. Configure extra shortcuts under Controls > Key Binds > wWaypoints.
- Updates preserve existing options.txt files; existing players can assign F12 themselves if they have not already received the local binding.
- Client-only: no Fedora server update is needed. No cloud sharing or multiplayer synchronization is promised by this pack addition.

Tested creating a local waypoint, saving/reloading it, and opening the native editor. The existing slab-rendering checks also passed. Cloud features and every combination of waypoint styles were not tested.

Reopen Comp Craft and use **Update & Play**. Existing worlds, keybinds, configs, maps and waypoints are preserved. The launcher remains at **1.1.1**; the pack is now **1.0.5**.
