Cyan Civilization **1.0.3** adds **A Good Place** for animated block placement.

- Uses the native Fabric **1.21-1.2.6** build for Minecraft 1.21.1: [official download](https://modrinth.com/mod/a-good-place/version/3xNxyWWQ).
- Enabled by default; toggle it under optional client-side mods in the launcher.
- Client-side visual addition. The Fedora server does not need updating for this release.
- Retains the animated launcher background and Slabbed rendering fixes from 1.0.2.
- Existing keybinds, settings, worlds and resource-pack selections are preserved.

Reopen Comp Craft, then use **Update & Play**. New players can use the attached installer.

The launcher remains at 1.1.1; the modpack is now 1.0.3.
